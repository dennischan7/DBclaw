# 数据库巡检工作流 (Health Check)

> 适用意图: `health_check` — 数据库健康检查、状态监控
> 风险等级: L0 (只读)
> 审批要求: 无

## 执行流程

```
用户输入 / 定时触发
  │
  ▼
┌─────────────────────┐
│ 1. 连接检查          │ → db_connect(instance)
│    - 连接可用性      │    超时=5s
│    - 响应延迟        │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 2. 元数据概览        │ → metadata_read(instance)
│    - 数据库/表列表   │    表数量、总大小
│    - 表空间使用      │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 3. 性能指标检查      │ → 方言特定查询
│    PG: pg_stat_*     │    活跃连接、等待事件
│    MySQL: SHOW STATUS│    慢查询计数、缓冲命中率
│    Oracle: V$视图    │    SGA/PGA使用
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 4. 生成巡检报告      │ → Markdown格式
│    - 健康状态概览    │    🟢正常 / 🟡警告 / 🔴异常
│    - 性能指标        │
│    - 优化建议        │
└─────────────────────┘
```

## 巡检指标项

| 指标 | 正常范围 | 警告阈值 |
|------|---------|---------|
| 连接响应时间 | < 100ms | > 500ms |
| 活跃连接数 | < max_connections * 80% | > 80% |
| 缓冲池命中率 | > 95% | < 90% |
| 磁盘空间使用 | < 80% | > 85% |
| 慢查询占比 | < 1% | > 5% |
| 死锁次数 (/小时) | 0 | > 1 |
