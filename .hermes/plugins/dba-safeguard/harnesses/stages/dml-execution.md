# DML 执行工作流 (DML Execution)

> 适用意图: `dml_insert`, `dml_update`, `dml_delete`
> 风险等级: L1 (INSERT) / L2 (UPDATE/DELETE with WHERE) / L4 (DELETE/UPDATE without WHERE)
> 审批要求: L1通知 / L2人工确认 / L4管理员审批

## 执行流程

```
用户输入/AI生成SQL
  │
  ▼
┌─────────────────────┐
│ 1. 意图分类          │ → 确认为DML操作，识别子类型
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 2. 知识库检索        │ → library_search(syntax, db_type, version)
│    - 确认语法规范    │    确保DML语法符合目标方言
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 3. SQL语法校验       │ → sql_validate(sql, dialect)
│    - 语法正确性      │    返回: valid, risk_level, operation_type
│    - WHERE子句检查   │    无WHERE → 升级到L4
│    - 风险等级定级    │
└──────────┬──────────┘
           │ (校验通过)
           ▼
┌─────────────────────┐
│ 4. 执行计划分析      │ → explain_analyze(sql, instance)
│    - 影响行数预估    │    预估 > 阈值 → 风险升级
│    - 锁范围分析      │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 5. 回滚脚本生成      │ → rollback_generate(sql, dialect, instance)
│    - INSERT → DELETE │    L2+ 强制要求
│    - UPDATE → 快照   │
│    - DELETE → 快照   │
└──────────┬──────────┘
           │ (L2+必须成功)
           ▼
┌─────────────────────┐
│ 6. 人工审批 (L2+)    │ → 展示SQL + 回滚脚本 + 风险分析
│    - L1: 通知后放行  │    等待用户确认
│    - L2: 人工确认    │
│    - L3-L4: 管理员   │
└──────────┬──────────┘
           │ (审批通过)
           ▼
┌─────────────────────┐
│ 7. 安全执行          │ → db_execute(sql, instance, risk_level, rollback_sql)
│    - 事务封装        │    L2+: 执行前快照受影响行
│    - 超时控制        │    异常自动回滚
│    - 执行前快照(L2+) │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 8. 结果确认 + 审计   │ → 记录执行结果、影响行数、耗时
│    - 影响行数报告    │    保存回滚脚本供后续使用
│    - 审计全链路记录  │
└─────────────────────┘
```

## 风险升级规则

| 条件 | 升级目标 |
|------|---------|
| DELETE/UPDATE 无 WHERE | → L4 (强制阻断) |
| 预估影响行数 > 1000 | 当前等级 + 1 |
| 生产环境实例 | 当前等级 + 1 |
| 涉及核心业务表 | 当前等级 + 1 (需配置表清单) |

## 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 语法校验失败 | 返回错误 + 修正建议，打回重写 |
| 回滚脚本生成失败 | 警告用户需手动准备回滚，L2+阻断 |
| 审批被拒绝 | 终止执行，记录审计 |
| 执行超时 | 自动回滚事务，记录审计 |
| 执行失败 | 自动回滚事务，返回错误详情 |
