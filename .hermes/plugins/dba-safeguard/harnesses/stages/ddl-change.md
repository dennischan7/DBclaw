# DDL 变更工作流 (DDL Change)

> 适用意图: `ddl_create`, `ddl_alter`, `ddl_drop`, `ddl_truncate`
> 风险等级: L2 (CREATE/ALTER ADD) / L3 (ALTER DROP/MODIFY, TRUNCATE) / L4 (DROP TABLE/DATABASE)
> 审批要求: L2人工确认 / L3-L4管理员审批

## 执行流程

```
用户需求
  │
  ▼
┌─────────────────────┐
│ 1. 意图分类          │ → 确认为DDL操作，识别子类型
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 2. 知识库检索        │ → library_search(ddl_syntax, db_type, version)
│    - 确认DDL语法规范 │    确保语法符合目标方言
│    - 检查版本兼容性  │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 3. 元数据预检        │ → metadata_read(table, instance)
│    - 目标表是否存在  │    CREATE: 确认表不存在
│    - 当前表结构      │    ALTER/DROP: 确认表存在
│    - 依赖关系检查    │    外键/视图/触发器依赖
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 4. SQL语法校验       │ → sql_validate(sql, dialect)
│    - 语法正确性      │    返回: valid, risk_level
│    - 风险等级定级    │
└──────────┬──────────┘
           │ (校验通过)
           ▼
┌─────────────────────┐
│ 5. 回滚脚本生成      │ → rollback_generate(sql, dialect, instance)
│    - CREATE → DROP   │    从元数据获取精确回滚
│    - ALTER ADD→DROP  │
│    - ALTER DROP→ADD  │ (需列定义)
│    - DROP → CREATE   │ (需完整DDL备份)
└──────────┬──────────┘
           │ (必须成功)
           ▼
┌─────────────────────┐
│ 6. 变更审批          │ → 展示: 变更SQL + 回滚脚本 + 影响分析
│    - L2: 人工确认    │    展示当前表结构 vs 变更后
│    - L3: 管理员审批  │
│    - L4: 强制阻断    │ (需管理员 + 双人确认)
└──────────┬──────────┘
           │ (审批通过)
           ▼
┌─────────────────────┐
│ 7. 安全执行          │ → db_execute(sql, instance, risk_level, rollback_sql)
│    - 管理员连接      │    DDL一般不可事务化(MySQL)
│    - 超时控制        │    PG支持事务DDL
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 8. 变更验证 + 审计   │ → metadata_read 验证变更结果
│    - 确认结构已变更  │    记录变更前后对比
│    - 审计全链路记录  │
└─────────────────────┘
```

## DDL特殊注意事项

| 数据库 | DDL事务支持 | 注意事项 |
|--------|-----------|---------|
| PostgreSQL | ✅ 支持事务DDL | 可在事务中回滚DDL |
| MySQL | ❌ 隐式提交 | DDL自动COMMIT，无法事务回滚 |
| Oracle | ❌ 隐式提交 | 同MySQL |
| SQL Server | ✅ 支持事务DDL | 可在事务中回滚DDL |

## 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 表不存在 (ALTER/DROP) | 元数据预检拦截，不进入校验 |
| 表已存在 (CREATE) | 建议使用 IF NOT EXISTS |
| 回滚脚本无法生成 (DROP 无DDL备份) | 警告：执行后不可逆，升级审批级别 |
| 列定义获取失败 | 降级为注释型回滚脚本 |
