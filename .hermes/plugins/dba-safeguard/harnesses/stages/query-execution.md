# 查询执行工作流 (Query Execution)

> 适用意图: `query` — SELECT, SHOW, DESCRIBE, EXPLAIN 等只读操作
> 风险等级: L0 (READONLY)
> 审批要求: 无

## 执行流程

```
用户输入
  │
  ▼
┌─────────────────────┐
│ 1. 意图分类          │ → 确认为查询类操作
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 2. SQL语法校验       │ → sql_validate(sql, dialect)
│    - 语法正确性      │    返回: valid, risk_level, warnings
│    - 方言兼容性      │
│    - 风险等级确认=L0  │
└──────────┬──────────┘
           │ (校验通过)
           ▼
┌─────────────────────┐
│ 3. 执行计划分析      │ → explain_analyze(sql, instance)
│    - 全表扫描检测    │    返回: plan, warnings, estimated_rows
│    - 扫描行数预估    │
│    - 性能风险标记    │
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 4. 安全执行          │ → db_execute(sql, instance, risk_level=0)
│    - 只读连接        │    返回: data, execution_time_ms
│    - 超时控制        │
│    - 结果截断(≤1000行)│
└──────────┬──────────┘
           │
           ▼
┌─────────────────────┐
│ 5. 审计记录          │ → 自动记录(由safe_executor内部完成)
│    - SQL + 结果摘要   │
│    - 执行耗时        │
└─────────────────────┘
```

## 异常处理

| 异常场景 | 处理方式 |
|---------|---------|
| 语法校验失败 | 返回错误详情 + 修正建议，不执行 |
| 执行计划发现全表扫描 | 警告用户，建议添加索引，仍允许执行 |
| 预估扫描行数 > 100000 | 警告用户，建议添加 LIMIT |
| 执行超时 | 返回超时错误，记录审计 |

## 知识库触发条件

- 用户查询涉及非标准语法时，触发 `library_search` 查阅官方文档
- 例: `SELECT ... FOR UPDATE` → 检索当前方言的锁机制文档
