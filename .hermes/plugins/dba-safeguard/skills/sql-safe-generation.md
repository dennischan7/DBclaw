# SQL Safe Generation Skill

## 目标
安全地生成SQL语句，确保语法正确、方言兼容、风险可控。

## 工作流程

### 1. 明确需求
- 确认目标数据库类型和版本（MySQL 5.7/8.0, PostgreSQL 14/15/16, Oracle 19c/21c/23c, Hive等）
- 确认操作意图（查询/修改/DDL）
- 确认影响范围（单行/批量/全表）

### 2. 知识库检索
**必须先调用 `library_search`** 查阅目标数据库版本的官方文档：
- 确认语法关键词在该版本是否支持
- 确认函数/数据类型的方言差异
- 确认已知限制和注意事项

### 3. SQL生成
- 使用标准SQL语法，避免方言不兼容
- DML语句**必须包含WHERE条件**
- SELECT避免使用 `SELECT *`，明确列名
- 合理使用别名提高可读性

### 4. 语法校验
调用 `sql_validate` 进行校验：
- 语法正确性
- 方言兼容性
- 风险等级判定
- 危险模式检测

### 5. 校验失败处理
如果校验失败，最多自动重写3轮：
1. 分析错误信息
2. 再次查阅 `library_search` 确认正确语法
3. 修正SQL并重新校验

## 安全红线
- **绝不生成无WHERE的DELETE/UPDATE**
- **绝不生成DROP DATABASE/TABLE除非用户明确要求**
- **生产环境操作必须包含事务控制**
- **大批量操作必须分批执行建议**
