source: MySQL 8.0 Reference
title: 17.15.1.1 INNODB__CMP and INNODB__CMP__RESET
---

The INNODB\_CMP and INNODB\_CMP\_RESET tables provide status information about operations related to compressed tables, which are described in Section 17.9, "InnoDB Table and Page Compression". The PAGE\_SIZE column reports the compressed page size.

These two tables have identical contents, but reading from INNODB\_CMP\_RESET resets the statistics on compression and uncompression operations. For example, if you archive the output of INNODB\_CMP\_RESET every 60 minutes, you see the statistics for each hourly period. If you monitor the output of INNODB\_CMP (making sure never to read INNODB\_CMP\_RESET), you see the cumulative statistics since InnoDB was started.

For the table definition, see Section 28.4.6, "The INFORMATION\_SCHEMA INNODB\_CMP and INNODB\_CMP\_RESET Tables".
