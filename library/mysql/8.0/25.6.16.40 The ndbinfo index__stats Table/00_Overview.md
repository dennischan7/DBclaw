The index\_stats table provides basic information about NDB index statistics.

More complete index statistics information can be obtained using the ndb\_index\_stat utility.

The index\_stats table contains the following columns:

• index\_id

Index ID

• index\_version

Index version

• sample\_version

Sample version

# **Notes**

This table was added in NDB 8.0.28.
