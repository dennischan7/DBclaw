source: MySQL 5.7 Reference
title: 13.6.6.1 Cursor CLOSE Statement
---

```
CLOSE cursor_name
```

This statement closes a previously opened cursor. For an example, see [Section 13.6.6, "Cursors"](#page-59-1).

An error occurs if the cursor is not open.

If not closed explicitly, a cursor is closed at the end of the [BEGIN ... END](#page-52-0) block in which it was declared.
