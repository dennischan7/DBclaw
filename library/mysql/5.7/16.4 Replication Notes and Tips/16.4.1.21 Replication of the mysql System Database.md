source: MySQL 5.7 Reference
title: 16.4.1.21 Replication of the mysql System Database
---

Data modification statements made to tables in the mysql database are replicated according to the value of [binlog\\_format](#page-83-0); if this value is MIXED, these statements are replicated using row-based format. However, statements that would normally update this information indirectly—such GRANT, REVOKE, and statements manipulating triggers, stored routines, and views—are replicated to replicas using statement-based replication.
