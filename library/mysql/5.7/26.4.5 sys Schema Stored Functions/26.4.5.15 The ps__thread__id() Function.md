title: 26.4.5.15 The ps__thread__id() Function
---

Returns the Performance Schema thread ID assigned to a given connection ID, or the thread ID for the current connection if the connection ID is NULL.

### **Parameters**

• in\_connection\_id BIGINT UNSIGNED: The ID of the connection for which to return the thread ID. This is a value of the type given in the PROCESSLIST\_ID column of the Performance Schema threads table or the Id column of SHOW PROCESSLIST output.

### **Return Value**

A BIGINT UNSIGNED value.

### **Example**

```
mysql> SELECT sys.ps_thread_id(260);
+-----------------------+
| sys.ps_thread_id(260) |
+-----------------------+
| 285 |
+-----------------------+
```
