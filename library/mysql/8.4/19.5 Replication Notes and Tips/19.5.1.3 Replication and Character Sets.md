source: MySQL 8.4 Reference
title: 19.5.1.3 Replication and Character Sets
---

The following applies to replication between MySQL servers that use different character sets:

• If the source has databases with a character set different from the global character\_set\_server value, you should design your CREATE TABLE statements so that they do not implicitly rely on the database default character set. A good workaround is to state the character set and collation explicitly in CREATE TABLE statements.
