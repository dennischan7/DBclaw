MySQL supports two aggregate JSON functions JSON\_ARRAYAGG() and JSON\_OBJECTAGG(). See Section 14.19, "Aggregate Functions", for descriptions of these.

MySQL also supports "pretty-printing" of JSON values in an easy-to-read format, using the [JSON\\_PRETTY\(\)](#page-185-0) function. You can see how much storage space a given JSON value takes up, and how much space remains for additional storage, using [JSON\\_STORAGE\\_SIZE\(\)](#page-188-0) and [JSON\\_STORAGE\\_FREE\(\)](#page-186-0), respectively. For complete descriptions of these functions, see [Section 14.17.8, "JSON Utility Functions".](#page-185-1)
