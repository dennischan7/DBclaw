# Oracle Compliance with SQL/RPR:2012

INCITS 500:2012, also known as SQL/RPR:2012 (for "Row Pattern Recognition"), was adopted in 2012. Oracle fully supports Feature R010, "Row pattern recognition: `FROM` clause" defined in this standard.
