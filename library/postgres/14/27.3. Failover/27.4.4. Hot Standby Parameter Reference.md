title: 27.4.4. Hot Standby Parameter Reference
---

Various parameters have been mentioned above in [Section 27.4.2](#page-193-0) and [Section 27.4.3](#page-195-0).

On the primary, parameters [wal\\_level](#page-37-1) and [vacuum\\_defer\\_cleanup\\_age](#page-49-2) can be used. [max\\_stand](#page-50-2)[by\\_archive\\_delay](#page-50-2) and [max\\_standby\\_streaming\\_delay](#page-50-3) have no effect if set on the primary.

On the standby, parameters [hot\\_standby,](#page-50-0) [max\\_standby\\_archive\\_delay](#page-50-2) and [max\\_standby\\_stream](#page-50-3)[ing\\_delay](#page-50-3) can be used. [vacuum\\_defer\\_cleanup\\_age](#page-49-2) has no effect as long as the server remains in standby mode, though it will become relevant if the standby becomes primary.
