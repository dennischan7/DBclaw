title: 57.2.12. FDW Routines for Reparameterization of Paths
---

```
List *
ReparameterizeForeignPathByChild(PlannerInfo *root, List
 *fdw_private,
 RelOptInfo *child_rel);
```

This function is called while converting a path parameterized by the top-most parent of the given child relation child\_rel to be parameterized by the child relation. The function is used to reparameterize any paths or translate any expression nodes saved in the given fdw\_private member of a ForeignPath. The callback may use reparameterize\_path\_by\_child, adjust\_appendrel\_attrs or adjust\_appendrel\_attrs\_multilevel as required.
