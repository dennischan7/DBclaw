wal\_level must be set to logical.

max\_replication\_slots must be set to at least the number of subscriptions expected to connect, plus some reserve for table synchronization.

max\_wal\_senders should be set to at least the same as max\_replication\_slots, plus the number of physical replicas that are connected at the same time.

Logical replication walsender is also affected by wal\_sender\_timeout.
