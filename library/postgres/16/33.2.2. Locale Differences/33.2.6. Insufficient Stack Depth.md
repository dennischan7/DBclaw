---
source: PostgreSQL 16 Reference
title: 33.2.6. Insufficient Stack Depth
---

If the errors test results in a server crash at the select infinite\_recurse() command, it means that the platform's limit on process stack size is smaller than the max\_stack\_depth parameter indicates. This can be fixed by running the server under a higher stack size limit (4MB is recommended with the default value of max\_stack\_depth). If you are unable to do that, an alternative is to reduce the value of max\_stack\_depth.

On platforms supporting getrlimit(), the server should automatically choose a safe value of max\_stack\_depth; so unless you've manually overridden this setting, a failure of this kind is a reportable bug.
