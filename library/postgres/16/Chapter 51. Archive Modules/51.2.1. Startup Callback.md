title: 51.2.1. Startup Callback
---

The startup\_cb callback is called shortly after the module is loaded. This callback can be used to perform any additional initialization required. If the archive module has any state, it can use state- >private\_data to store it.

```
typedef void (*ArchiveStartupCB) (ArchiveModuleState *state);
```
