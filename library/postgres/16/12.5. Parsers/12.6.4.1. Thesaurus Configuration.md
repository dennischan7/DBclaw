---
source: PostgreSQL 16 Reference
title: 12.6.4.1. Thesaurus Configuration
---

To define a new thesaurus dictionary, use the thesaurus template. For example:

```
CREATE TEXT SEARCH DICTIONARY thesaurus_simple (
 TEMPLATE = thesaurus,
 DictFile = mythesaurus,
 Dictionary = pg_catalog.english_stem
);
```

### Here:

- thesaurus\_simple is the new dictionary's name
- mythesaurus is the base name of the thesaurus configuration file. (Its full name will be \$SHAREDIR/tsearch\_data/mythesaurus.ths, where \$SHAREDIR means the installation shared-data directory.)
- pg\_catalog.english\_stem is the subdictionary (here, a Snowball English stemmer) to use for thesaurus normalization. Notice that the subdictionary will have its own configuration (for example, stop words), which is not shown here.

Now it is possible to bind the thesaurus dictionary thesaurus\_simple to the desired token types in a configuration, for example:

```
ALTER TEXT SEARCH CONFIGURATION russian
 ALTER MAPPING FOR asciiword, asciihword, hword_asciipart
 WITH thesaurus_simple;
```
