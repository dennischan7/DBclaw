[Table 19.2](#page-34-0) summarizes the files that are relevant to the SSL setup on the server. (The shown file names are default names. The locally configured names could be different.)

<span id="page-34-0"></span>

|  |  |  | Table 19.2. SSL Server File Usage |  |  |
|--|--|--|-----------------------------------|--|--|
|--|--|--|-----------------------------------|--|--|

| File                                    | Contents                                            | Effect                                                                                                         |
|-----------------------------------------|-----------------------------------------------------|----------------------------------------------------------------------------------------------------------------|
| ssl_cert_file (\$PGDA<br>TA/server.crt) | server certificate                                  | sent to client to indicate server's<br>identity                                                                |
| ssl_key_file (\$PGDA<br>TA/server.key)  | server private key                                  | proves server certificate was<br>sent by the owner; does not in<br>dicate certificate owner is trust<br>worthy |
| ssl_ca_file                             | trusted certificate authorities                     | checks that client certificate is<br>signed by a trusted certificate<br>authority                              |
| ssl_crl_file                            | certificates revoked by certifi<br>cate authorities | client certificate must not be on<br>this list                                                                 |

The server reads these files at server start and whenever the server configuration is reloaded. On Windows systems, they are also re-read whenever a new backend process is spawned for a new client connection.

If an error in these files is detected at server start, the server will refuse to start. But if an error is detected during a configuration reload, the files are ignored and the old SSL configuration continues to be used. On Windows systems, if an error in these files is detected at backend start, that backend will be unable to establish an SSL connection. In all these cases, the error condition is reported in the server log.
