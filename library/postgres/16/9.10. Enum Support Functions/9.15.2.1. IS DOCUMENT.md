source: PostgreSQL 16 Reference
title: 9.15.2.1. IS DOCUMENT
---

```
xml IS DOCUMENT → boolean
```

The expression IS DOCUMENT returns true if the argument XML value is a proper XML document, false if it is not (that is, it is a content fragment), or null if the argument is null. See [Section 8.13](#page-15-0) about the difference between documents and content fragments.
