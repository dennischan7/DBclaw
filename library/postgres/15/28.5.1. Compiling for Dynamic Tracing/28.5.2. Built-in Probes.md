A number of standard probes are provided in the source code, as shown in Table 28.47; Table 28.48 shows the types used in the probes. More probes can certainly be added to enhance PostgreSQL's observability.

<span id="page-52-0"></span>**Table 28.47. Built-in DTrace Probes**

|-------------------------|----------------------|-------------------------------------------------------------------------------------------|
| transac-<br>tion-start  | (LocalTransactionId) | Probe that fires at the start of a new transaction. arg0 is the transaction ID.           |
| transaction-com-<br>mit | (LocalTransactionId) | Probe that fires when a transaction completes successfully. arg0 is the transaction ID.   |
| transac-<br>tion-abort  | (LocalTransactionId) | Probe that fires when a transaction completes unsuccessfully. arg0 is the transaction ID. |
| query-start             | (const char *)       | Probe that fires when the processing of a query is started. arg0 is the query string.     |
